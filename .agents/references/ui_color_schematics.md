# UI Color Scheme

## Brand Core Colors

| Name           |       Hex | Suggested use                                        |
| -------------- | --------: | ---------------------------------------------------- |
| **Mint**       | `#B9D6C6` | Primary brand softness, active states, light buttons |
| **Sage**       | `#7FA392` | Main brand color, CTAs, headings                     |
| **Deep Sage**  | `#5E7F70` | Strong text, icons, dark brand accents               |
| **Coral**      | `#FF8F7A` | Logo “Me”, spending alerts, gentle warnings          |
| **Blush**      | `#FFD6C7` | Soft alert backgrounds, badges, highlights           |
| **Cream**      | `#FFF7EC` | Main app background                                  |
| **Warm Beige** | `#F2E7D4` | Secondary surfaces, cards, panels                    |
| **Sunshine**   | `#F7C24B` | Coin accents, rewards, savings highlights            |
| **Pebble**     | `#E6E9E4` | Borders, dividers, neutral UI areas                  |
